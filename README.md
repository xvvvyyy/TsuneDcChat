TsuneDcChat

A custom Discord bot chat interface that runs directly in your browser.

---

About

TsuneDcChat is a small side project I made out of boredom and curiosity. I wanted to experiment with the Discord API and see if I could build my own way of interacting with a Discord bot.

Nothing too serious, just something I felt like making.

Features

- Browse servers and text channels
- View messages from real users and bots
- Send messages through your bot
- Reply to messages
- Delete messages sent by your bot
- View avatars and timestamps
- Six different themes
- Automatic message refreshing
- Demo mode
- Manual/automatic channel ID input

Getting Started

There is no installation or build process required.

1. Download or clone the repository.

2. Open the "main" folder.

3. Double-click "code.html".

4. The page will open in your browser.

Setting Up Your Bot

To connect a Discord bot, create one through the "Discord Developer Portal" (https://discord.com/developers/applications).

Copy your bot token and paste it into the Settings tab. Depending on your setup, you may also need a CORS proxy for API requests.

Your bot can only access servers and channels it has permission to access.

«Keep your bot token private. Never upload it to GitHub or share it with anyone.»
